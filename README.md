Manage gettext catalogs and CakePHP database translations through an application backend. Import POT and PO files, edit translations, export PO catalogs and inspect TranslateBehavior entries. Optional engines provide machine-translation suggestions.

Read the [documentation](https://dereuromark.github.io/cakephp-translate/), starting with [Installation](https://dereuromark.github.io/cakephp-translate/guide/installation) and [Getting started](https://dereuromark.github.io/cakephp-translate/guide/getting-started).

Composer declares the supported PHP and CakePHP ranges. For older applications, see the [version map](https://github.com/dereuromark/cakephp-translate/wiki#cakephp-version-map).

The admin interface requires an explicit access gate and inherits your application’s AppController. See [Configuration](https://dereuromark.github.io/cakephp-translate/reference/configuration) for access settings and optional integrations.
